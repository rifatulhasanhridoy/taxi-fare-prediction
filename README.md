# 🚕 Taxi Trip Fare Prediction

A machine learning project that predicts taxi trip fares based on distance,
time, traffic conditions, and weather. Built as part of **WM-ASDS04:
Introduction to Data Science with Python** at Jahangirnagar University.

## 📂 Dataset
- **Source:** [Kaggle — denkuznetz/taxi-price-prediction](https://www.kaggle.com/datasets/denkuznetz/taxi-price-prediction)
- 1,000 records | 11 features | Regression task

---

## ⚙️ Methods
- Data cleaning & Label Encoding
- Exploratory Data Analysis (4 visualisations)
- Linear Regression (baseline)
- Random Forest Regressor

---

## 📊 Results
| Model | R² | MAE | RMSE |
|---|---|---|---|
| Linear Regression | 0.7700 | 9.84 | 13.82 |
| **Random Forest** | **0.9288** | **5.41** | **7.69** |

✅ **Random Forest** was the better model with 45% lower prediction error.
